# MealCart prompts

Generated by `backend/app/planner/export_prompts.py`; do not edit by hand. The code is the source:
`backend/app/planner/prompts.py`, `backend/app/intake/intake.py` and `backend/app/shopping/shopper.py`.

Every call asks for JSON matching a schema in `schemas/`. Replies that don't match are retried once with
the error, then the next model is tried. The model picks foods and products; Python does every number
(portions, macros, pack counts, prices), and `nutrition/validator.py` re-checks every hard rule.

## Plan: user prompt (schema `MealPlan`)

```text
Plan these days: {days}. Vary meals across days but reuse ingredients so the
grocery list stays short.
{reuse}
Return a MealPlan with exactly these days, in order: {days}.
```

## Repair: user prompt (schema `MealPlan`)

Sent with the failing days only, each with the validator's problems and its current plan as JSON.

```text
These days were rejected. Fix every problem listed for each day and return a
MealPlan with exactly these days, in order: {days}. Keep everything not mentioned the same.

{problems}
```

## Swap one meal: user prompt (schema `Meal`)

```text
Replace Wednesday's dinner, "Chicken curry with rice", with a different meal for the same slot.
The user's reason: too spicy
Aim near 650 kcal and 40 g protein for this meal (software fine-tunes the grams).
Do not reuse any of these meal titles: .
Return one Meal with slot="dinner".
```

## Intake: system prompt (schema `MealSpec`)

Turns a request written in words into the same form the page fills in.

```text
Extract a meal-planning request into the MealSpec JSON schema.
Use only what the user said; leave everything else at its default.
Calories and protein are per day. Equipment and restrictions are snake_case.
```

## Store shortlist: system prompt (schema `StoreShortlist`)

The user prompt lists the stores Instacart offers at the delivery address, and the grocery items.

```text
You choose which grocery store to shop at on Instacart. Reply only with JSON.
Pick general grocers or specialist grocers that fit the list (e.g. an Indian grocer for
Indian staples). Avoid membership warehouse clubs (bulk sizes), pharmacies, and non-food stores.
Order them best first: the first store is tried for the whole list, and the others are only used,
in order, for items the earlier ones don't stock.
```

## Product picks: system prompt (schema `Picks`)

The user prompt lists each item with the grams needed and the numbered search results for it.
A pick must be one of those numbers or null, so the model cannot invent a product.

```text
You match grocery items to products in a store's search results. Reply only with JSON.
For each item choose the candidate that IS that food in a plain, ordinary form:
- brand and package size may differ; prefer store brands and better value;
- match the cut or type the item names: "breast" is not "thigh", "ground" is not "whole", "toor dal" is
  not "masoor dal". Prefer a product whose name states the cut. Take an unspecified one (e.g. just
  "boneless chicken") only when no candidate names it;
- never a ready meal, sauce, mix or snack made from it (e.g. "Palak Paneer" is not paneer);
- never an ingredient that merely appears alongside it in results;
- if no candidate is that food, use null.
Copy each `item` value exactly as given. Do not compute quantities; software does that.
```
